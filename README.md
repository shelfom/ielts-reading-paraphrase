# IELTS Reading Paraphrase · 雅思阅读同义替换

Match the words in the question to the words in the passage — the core IELTS Reading skill.

把题目里的说法和原文里的说法配对，练的正是雅思阅读最核心的能力。

**Free · no sign-up · works on phones.** Part of [Free English Learning Tools](https://github.com/shelfom/free-english-learning-tools), 11 free websites for IELTS, Cambridge English and academic vocabulary.

**[▶ Open the site](https://ielts-reading-para.coze.site/)** (fastest in mainland China) · **[🌍 Global mirror](https://shelfom.github.io/ielts-reading-paraphrase/)** (GitHub Pages)

[![IELTS Reading Paraphrase screenshot](docs/screenshot.jpg)](https://ielts-reading-para.coze.site/)

## What's inside

- Cambridge IELTS 11–20: 120 passages, 2,200 unique paraphrase pairs, 485 rounds
- Click a phrase from the question, then its paraphrase from the passage
- Contents menu for every book, progress kept on your device
- Light and dark themes, works on phones

## Run it locally

```bash
pnpm install
pnpm dev
```
